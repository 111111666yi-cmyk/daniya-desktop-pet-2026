## 4. 启动流程检查 (Startup Sequence)
项目完整的启动流程追踪如下：
1. `main.py` -> 调用 `src.app.run()` 入口函数。
2. 启动 `QApplication`。
3. 实例化 `SetupStateManager`：
   - 检查 `config/setup_config.json`。若首次运行未完成，打开 `FirstRunWizard` 引导界面让用户选择本地/云端模式，并生成默认配置。
4. 实例化 `AppController`：
   - 实例化 `ConfigManager` 加载 `app_config.json`（如缺失或损坏自动安全重建并备份）。
   - 启动关联数据管理器：`HistoryManager`、`ProfileManager`、`AffinityManager`、`AssetManager`。
   - 启动 API 通信服务：`ChatClient` -> 实例化 `ProviderManager`。
   - 启动陪伴助手管理器：`NotesManager`、`ReminderManager`、`TimeEventManager`、`DayNightManager`、`BookmarkManager`。
   - 实例化 `DaniyaEngineAdapter` 绑定角色行为主链路。
   - 创建 `PetWindow`（桌宠主窗口）并初始化 UI，延迟绑定 `AnimationManager` 与防抖物理事件。
   - 加载右键菜单 `MenuManager` 并通过 QSS 样式渲染。
5. 启动 `QTimer` 定时调度服务（防抖、报时、闲聊、日程扫描等）。
6. 进入事件轮询 `sys.exit(app.exec())`。
- **异常捕获与安全性**：启动期间的 I/O 异常和配置文件解析错误（如 JSON/YAML 损坏）均通过 try-except 机制转移到 fallback 缺省状态或提示备份，无任何未捕获的崩溃或模块循环导入风险。

## 5. 配置系统检查 (Configuration Resiliency)
- **自适应修复与备份**：`ConfigManager` 在读取 JSON 文件时一旦遭遇 `JSONDecodeError`，将把损坏的配置文件自动重命名备份至 `*.broken-YYYYMMDDHHMMSS`，随后将内存中完整的 `DEFAULT_APP_CONFIG` 重新写入文件。
- **合并合并策略**：在加载时会通过 `deep_merge` 将未定义或新增的默认字段智能同步到损坏/残缺的配置文件中，完全实现免维护运行。

## 6. 资源系统检查 (Asset System & DPI Fallback)
- **多环境兼容**：使用 `src/utils.py` 内部的 `bundled_root` 与 `runtime_root` 对 PyInstaller 环境中的 `sys._MEIPASS` 进行判断，开发环境与 EXE 独立运行环境下资源加载定位一致，无路径偏移。
- **缺图 Fallback**：若 `assets/private/` 中的立绘或 manifest 不存在，动作系统会自动捕获该缺失，平滑回退到读取 `assets/placeholder/daniya_summer/` 中的标准公开透明 PNG，绝对不触发界面图片未找到崩溃。

## 7. UI 窗口系统检查 (UI & Window Subsystems)
- **窗口物理属性**：`PetWindow` 具备 `Qt.FramelessWindowHint` (无边框)、`Qt.WA_TranslucentBackground` (透明画板背景)、`Qt.WindowStaysOnTopHint` (窗口置顶) 属性。
- **拖拽与防边缘溢出**：重写了拖拽和鼠标移动逻辑，在拖拽松开和尺寸变更后，通过 `_clamped_position` 进行显示器物理分辨率边缘检测，防止宠物被拖曳出屏幕。支持重启后恢复上次坐标。
- **高 DPI 缩放**：采用设备像素比 `dpr` 动态缩放 QPixmap，并在 `_resize_to_content` 时通过映射绝对全局坐标修正相对偏移，解决了在高分屏下调整宠物尺寸或说话时立绘在屏幕上移位、抖动的问题。
- **输入框与气泡折叠**：
  - 输入框（`InputBar`）带有失焦、发送、点击宠物自动收起折叠逻辑。
  - 气泡（`ModernBubble`）显示时自动计算高度，支持鼠标滑入暂停隐藏、双击复制文本。

## 8. API 对话系统检查 (API & Connection Failovers)
- **API Key 隔离与 Fallback**：
  - 若根目录下不存在 `.env`，或 `.env` 内部的 `DEEPSEEK_API_KEY` 为空/缺失，程序会平稳且友好地识别为本地离线模式。
  - 聊天界面将正常回退到 friendly fallback：显示离线陪玩提示（*“达妮娅现在还没有连上大脑...”*），不会因为找不到 Key 发生闪退或空指针异常。
- **连接超时与异步保障**：
  - 网络请求与 LLM 接口调用通过底层的边界异常层进行包装，发生 401（AuthError）、429（RateLimitError）、5xx（ServerError）或超时连接失败时，将抛出统一异常并返回错误占位文案，后台 `ChatWorker` 线程（QThread）异常不影响主 GUI 的操作，UI 不出现白屏或卡死。

## 9. 动作 Manifest 系统检查 (Action Manifest Subsystem)
- **文件检查与解析**：
  - 系统启动时通过 `ActionManifest` 类优先加载 `assets/private/manifest.json`，缺失则加载内置 `assets/placeholder/manifest.json`。
  - 动作配置校验机制会将错误的字段使用 `DEFAULT_MANIFEST` 的通用动作帧自适应补全。
- **对齐与抖动控制**：
  - 立绘和动作容器采用了严格的正方形固定画板边界（`max(logical_height, logical_width)`），并在 QPainter 中执行居中底端对齐，切换动作时宠物不会产生物理跳动或缩进抖动。
  - 拖拽和说话结束后，状态调度器 `StateManager` 将正确下发 `"idle"` 指令，让动画状态重置。

## 10. 本地陪伴功能检查 (Local Companion Tools)
- **便签功能**：`NotesManager` 能够将用户便签内容正确格式化保存至 `data/notes.txt`，空内容直接拦截并进行提示，不予写入。
- **日程提醒**：`ReminderManager` 通过内部 `QTimer` 每 30 秒轮询一次时间是否到期。到期后将发出系统级 `reminder_due` 事件，展示 `QMessageBox` 置顶提醒，在用户确认后将 `done` 标置为 `True`，避免重复弹窗。
- **报时与陪伴**：整点报时通过检测整点小时触发一次，且闲聊判定有 10 分钟的时间防刷冷却。
- **游戏正确性**：
  - 猜拳判定算法（平局、输、赢）逻辑严密。
  - 掷骰子产生 1-6 的随机整数，随机数正确落在 1-100。
  - 传送门通过 `webbrowser.open` 安全拉起系统浏览器，并前置拦截了非法 scheme（仅限 http/https），保障本地安全性。

## 11. 设置中心检查 (Settings Center Resilience)
- **修改生效与测试**：设置中心支持直接更新 `app_config.json` 与 `.env`，测试连接在后台 QThread 中并发运行并动态回显。修改宠物高度或切换模型后，触发底层管理器 `reload()` 直接生效，不需要重启程序。
- **安全隔离**：用户在 GUI 输入的明文 Key 会直接写入 `.env`，但设置页面的所有配置读取仅呈现脱敏的 `sk-****` 掩码，且 `model_profiles.json` 中没有以明文存储 Key。

## 12. 多模型系统检查 (Multi-Model Service Boundary)
- **Provider 结构隔离**：
  - 云端接入支持 DeepSeek、Claude、OpenAI 和 OpenAI-Compatible。
  - 任意一个 Provider 通信报错均隔离在底层的 API Boundary 级别，不向 GUI 泄露错误堆栈，也不会引起系统抛出主进程异常。

## 13. 本地模型系统检查 (Local Model Subsystem)
- **Ollama 适配**：
  - 支持通过本地 11434 端口拉取与调用 Ollama 运行的轻量大模型。
  - 模型不存在（404）时，边界层 `ollama_api.py` 会抛出 `ModelNotFoundError`，并允许控制器快速回退到本地 fallback 预设。

## 14. 打包发布检查 (Release Package Integration)
- **打包脚本 (`pack.bat`)**：
  - PyInstaller 打包流程能够生成全包含的绿色运行目录，自动复制必须的 `assets/placeholder/`、`assets/icons/`（关键图标）及文档、示例配置。
  - 自带的过滤指令（`robocopy /XD /XF`）在最后打包过程中完全剔除了所有的敏感文件（包括 `.env`，`assets/private/`，本地聊天记录 `data/`，测试模型 `models/`，`backups/` 目录以及任何 Python 缓存及 spec 文件）。
  - ZIP 打包结构：压缩路径已校正为 `release/%PACKAGE_NAME%` 根路径本身，解压后包含统一的父级目录。

## 15. Git / 开源安全检查 (Security & Git Compliance)
- **防泄露检测**：
  - 运行 `git status` 与 `git ls-files` 确认：无任何敏感资产（`.env`、`assets/private/`、`data/`、`models/`）被 Git 追踪。
