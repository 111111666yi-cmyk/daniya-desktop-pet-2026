# v0.76 Runtime Reliability

Status: automated phase checks passed on 2026-06-11. Physical long-run checks remain manual.

## Cold Start

`tools/measure_startup.py` runs the real application bootstrap with an offscreen Qt platform and an isolated temporary runtime directory. It records:

1. process start;
2. QApplication created;
3. runtime root resolved;
4. config loaded;
5. managers initialized;
6. character pack loaded;
7. main window created;
8. first show;
9. optional services initialized.

Latest local result:

- all 9 stages recorded;
- first show: 1832.15 ms;
- optional services: 1832.64 ms;
- traced peak memory: 0.76 MiB;
- no local paths or API keys in the report.

Timing varies by machine and is diagnostic evidence, not a fixed performance promise.

## Lazy Loading

- Optional feature configuration starts after first show.
- Relationship, event, memory, and system diagnostics load when their Settings Center page opens.
- History context reads only the latest requested records.
- Event summaries read a bounded tail instead of the complete JSONL file.
- Disabled idle, hourly, edge, global-click, walk, and idle-behavior timers remain stopped.
- Startup does not test a Provider connection, scan a user directory, load a model runtime, or play audio.

## Runtime Data

`tools/check_runtime_data.py` uses a temporary runtime directory and verifies:

- history rotation and bounded tail reads;
- event-log rotation and bounded tail reads;
- incomplete JSONL records are skipped;
- config, memory, relationship, reminder, and history writes are atomic;
- bad JSON is preserved and falls back safely;
- a failed read-only write does not crash;
- packaged mode uses a stable user-data root instead of the install directory.
