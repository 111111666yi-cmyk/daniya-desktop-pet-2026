# v0.70 Manual QA Checklist

Test the packaged `DaniyaSummerPet.exe`, not a source-mode `pythonw.exe main.py` process.

## Startup And Quiet Defaults

- [ ] Launch from a clean temporary runtime directory; no crash, white window, or missing character.
- [ ] Input is collapsed by default.
- [ ] Idle chat, hourly chime, idle movement, edge peek, system status, clipboard interaction, and focus mode are off by default.
- [ ] The pet does not move or speak repeatedly without a configured trigger.

## Core Interaction

- [ ] Dragging remains smooth and the pet returns to idle after release.
- [ ] Right-click menu opens once and its commands remain usable.
- [ ] Enabling the input bar makes it immediately visible; typing and sending work.
- [ ] Hiding and restoring the input bar persists after restart.
- [ ] Left and right edge peek work only when enabled and pause during typing, speech, dragging, Settings Center work, or focus mode.
- [ ] Bubbles, typewriter text, actions, and idle return do not overlap or remain stuck.

## Integrated Features

- [ ] Natural reminder creation, ambiguous-time confirmation, cancellation, and due reminder work.
- [ ] File organizer starts disabled, previews first, skips sensitive paths, and requires confirmation before moving files.
- [ ] System status starts disabled and does not flood alerts when enabled.
- [ ] Clipboard interaction starts disabled; sensitive text is blocked and preview text is not retained by default.
- [ ] Focus mode suppresses idle chat, hourly chime, edge peek, system status, and clipboard notices.

## Provider And Fallback

- [ ] An untested or failed Provider never displays a green PASS or “effective” state.
- [ ] Local fallback is labeled as fallback.
- [ ] A real Provider test uses a user-owned key; record provider, model, date, and result without recording the key.
- [ ] API failure returns a safe character response and does not freeze the UI.

## Settings And Character Packs

- [ ] All twelve Settings Center pages open without overlap or clipped controls.
- [ ] Memory notes are visible and can be cleared; runtime memory stays outside Git and the release package.
- [ ] Switching between Daniya and template preserves separate relationship state.
- [ ] Missing story/lore/manifest/action data falls back without a crash.
- [ ] `test_dummy` does not appear in the public character selector.

## Windows Environment

- [ ] Test at 100% DPI.
- [ ] Test any available non-100% DPI setting.
- [ ] Test all available monitors, including mixed-DPI movement when available.
- [ ] Close and restart the app; settings and window position persist as expected.
- [ ] Confirm antivirus/SmartScreen behavior for the downloaded zip and executable.

Record failures in `docs/KNOWN_ISSUES.md`; do not mark a manual item PASS without direct observation.
