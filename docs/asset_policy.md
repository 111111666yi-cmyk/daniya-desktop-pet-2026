# 素材政策

Daniya Summer Desktop Pet 是非官方粉丝项目，仓库只提供代码、占位素材和资源说明。

- 本项目不提供《鸣潮》官方游戏拆包资源。
- 本项目不提供未经授权的角色图片、语音、模型或 Live2D 资源。
- 用户可以在本地 `assets/private/` 放置自己拥有使用权的素材。
- GitHub 仓库只保留 `assets/placeholder/` 示例图。
- `assets/private/` 会被 `.gitignore` 忽略，不应提交到公开仓库。
- 达妮娅、《鸣潮》及相关角色、美术、商标、世界观权利归原权利方所有。
- 本项目仅用于学习 Python 桌面应用、桌宠交互和开源项目组织方式。
