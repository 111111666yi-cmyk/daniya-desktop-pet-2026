# 达妮娅桌宠 帮助

## 菜单结构

右键点击达妮娅可以打开菜单，功能分成几个大类：

- **基础**：显示/隐藏输入框、窗口置顶、调整大小。
- **对话**：查看聊天历史、修改人设、编辑你的个人档案。
- **陪伴**：记一笔、日程提醒、小游戏、传送门。
- **系统**：帮助、退出。

如果你看到的菜单只有简单的几项，没有分类，可能是旧版桌宠进程还没关。先退出旧的，再重新打开就好。

## 桌宠大小和清晰度

右键菜单"基础 / 大小"可以调整达妮娅的显示尺寸，从迷你到最大一共六档，默认推荐 96px。

放心调，程序会从高清原图重新缩放，不会影响你的原始素材。

## 素材放置

把你的立绘素材放到 `assets/private/daniya_summer/` 目录下就行。至少需要 `normal1.png` 和 `normal2.png` 两张图。

如果你还准备了不同动作的图（比如说话、拖动、睡觉等），可以按动作名建子文件夹放进去。没有的话程序会自动用默认立绘代替，不会出错。

素材推荐用高清大图（至少 512x512），这样缩放后才清晰。

## 输入和对话

1. 右键"基础 / 显示输入框"打开聊天框。
2. 输入内容后按回车发送。
3. 达妮娅思考时会显示提示。
4. 回复会用打字机效果一个字一个字蹦出来，同时达妮娅会切换口型动画。

没有配置 API 的话，达妮娅会用本地预设的回复跟你聊，不会报错。

## DeepSeek API 配置

想让达妮娅用 AI 回复，需要配置 API：

1. 把项目里的 `.env.example` 复制一份，改名为 `.env`。
2. 填入你的 API Key、接口地址和模型名称。
3. `.env` 文件放在和 `main.py` 同一层的目录下。

也可以在设置中心的"DeepSeek API 配置"页面直接填写，更方便。

## 陪伴功能

### 记一笔

右键"陪伴 / 记一笔"，可以快速记录一些想法或备忘。空内容不会保存。

### 日程提醒

右键"陪伴 / 日程提醒"，填写时间和事项。到了时间达妮娅会弹气泡提醒你，点击"知道了"就会标记为已完成。

### 整点报时

可以在设置中心开启。开启后每到整点，达妮娅会报一下时间。

### 闲聊陪伴

可以在设置中心开启。开启后如果你长时间没有互动，达妮娅会主动冒出一句话来找你聊天。点击、拖动、发消息都会重置计时。

### 空闲小动作

可以在设置中心开启。开启后如果你长时间没有操作，达妮娅会自己做一些小幅度的动作，比如晃一晃、伸个懒腰。

### 昼夜作息

晚上 11 点到早上 7 点是夜间模式。这段时间点击达妮娅时，她可能会温柔地提醒你该休息了，比如：

> 这么晚啦，要不要睡觉呀？

不会禁止你聊天，只是偶尔提醒一下。

### 小游戏

右键"陪伴 / 小游戏"可以玩：

- **猜拳**：石头剪刀布，你赢了好感度会加一点。
- **掷骰子**：随机掷出 1-6。
- **随机数**：生成 1-100 的随机数。

小游戏不需要联网。

### 传送门

右键"陪伴 / 传送门"可以快速打开常用网站。默认有 GitHub、ChatGPT、Bilibili、DeepSeek，可以在书签配置文件里自己添加。

## 人设和档案

- 右键"对话 / 人设设置"可以修改达妮娅的性格和说话方式。
- 右键"对话 / 用户档案"可以告诉达妮娅关于你的信息，让她更了解你。

修改保存后，下一次对话就会生效。

## 常见问题

### 菜单看起来不对

可能是旧版桌宠进程还在后台运行。先退出所有旧的桌宠，再重新打开就好。

### 看不到自己放的素材

确认图片放在了正确的位置：`assets/private/daniya_summer/` 目录下。如果没有找到你的素材，程序会显示默认的占位图。

### 对话没有回复

程序会自动切换到本地回复，不会卡住。如果你想用 AI 回复，检查一下：

- API Key 是否填对了。
- 网络是否能正常访问。
- 账户余额是否还够用。

### 桌宠看起来模糊

你放的原图可能太小了。推荐使用至少 512x512 的高清 PNG，越大越好。
