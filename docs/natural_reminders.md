# 自然语言提醒系统 (v0.61)

自然语言提醒系统允许用户以日常对话的口吻直接输入提醒设定。系统会智能解析时间并调用底层的 `ReminderManager` 保存提醒记录。

## 支持的语言格式

1. **相对时间**
   - 格式：`N 分钟后` / `N 小时后` / `N 天后` / `半小时后` / `两小时后`
   - 示例：`十分钟后提醒我喝水`，`半小时后叫我休息`
2. **绝对时间**
   - 格式：`今天/今晚/明天/后天` + `上午/下午/晚上/具体点数`
   - 示例：`今晚八点叫我看课程`，`明天早上九点提醒我复习`
3. **循环时间**
   - 格式：`每天/每周一` + `晚上/早上/具体点数`
   - 示例：`每天晚上十点提醒我睡觉`
4. **模糊时间（需二次确认）**
   - 格式：`一会儿` / `等会` / `有空时`
   - 行为：系统会弹窗/气泡询问具体时间，不直接保存。

## 隐私与安全

- 解析逻辑完全在本地离线运行（使用正则表达式与汉字数字映射规则）。
- 提醒数据全部写入本地 runtime data 目录 (`data/reminders.json`)，决不上传至云端或 API，且不会被提交到 Git。
- 混合意图（如“提醒我喝水，然后帮我分析 bug”）会被识别为 ambiguous，需要确认，以防误吞常规提问。

## 配置与控制

用户可以通过配置文件 `config/app_config.json` 开启或关闭该功能：

- **配置项名称**: `natural_reminder_enabled`
- **默认值**: `true` (默认开启)
- **行为说明**:
  - 当默认开启时，解析引擎**仅拦截明确具有提醒意图**的输入（如“提醒我”、“叫我”、“记得提醒”等），或者在已挂起提醒确认状态下输入的补充时间。任何非提醒意图、普通聊天及技术问题（如 Python 代码、日常提问）均不会被拦截，而是直接流转至普通聊天/LLM 链路，保证用户正常对话不被误吞。
  - 当配置设为 `false` 时，系统将完全绕过自然语言提醒解析逻辑（不调用 `NaturalReminderService`），已挂起的待确认状态将被立即清除，所有输入直接进入原普通聊天/LLM 链路。
- **设置中心集成**: 暂未在 GUI 设置中心面板中提供可视交互开关（本阶段标记为 `NEEDS POLISH` / `NOT WIRED`）。
