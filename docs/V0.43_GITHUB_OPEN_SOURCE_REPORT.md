## 15. characters/daniya Public Strategy

`characters/daniya/` is retained as the public example character pack for this repository.

Policy:

- It may be used as a working example for schema, special responses, relationship rules, action routing, and lore index retrieval.
- It must not contain runtime `data/daniya_relation/`.
- It must not contain chat history, reminders, notes, API config, or private assets.
- Users can replace or extend it locally with their own character pack.

Search check found no API key, relationship state file reference, user memory file, event log file, or chat history in `characters/daniya/`.
