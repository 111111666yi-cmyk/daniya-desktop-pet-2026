# 专注 / 游戏模式 (v0.65)

为了让用户在专注于工作或沉浸在游戏世界时不被打扰，桌宠引入了**专注/游戏模式**。该模式在激活时会自动减少或挂起不必要的随机弹泡和硬件资源警报。

## 专注状态下的桌宠行为

一旦进入专注模式，桌宠将进行静默克制调整：
1. **静默随机气泡**：暂停 idle 状态下随机弹出的小动作和对话气泡。
2. **挂起整点报时**：暂停每小时的整点语音/文字报时。
3. **静音系统/剪贴板警报**：系统硬件高负载提醒和剪贴板检测轻提示会被完全挂起或延迟。
4. **保留主动交互**：用户主动点击桌宠或在输入框发起对话时，桌宠仍会照常进行回复。
5. **保留紧急提醒**：极其重要的时间到期强提醒仍会静默弹出，但表现形式会极为克制，不打扰当前核心工作。
6. **平滑退出与恢复**：当退出专注模式时，系统状态与提醒规则原样恢复，并且**不会重复触发或堆叠**在专注期间积压的所有 pending 动作和气泡事件。

## 游戏自动感知隐私策略

1. **手动模式默认优先**：专注模式可以在设置中心一键手动开启或关闭。
2. **进程白名单本地校验**：
   - 自动检测功能（游戏模式）默认关闭。用户可在设置中心开启。
   - 开启后，系统在本地获取当前运行进程的名称，并与本地的白名单游戏列表（如 `eldenring.exe`, `lol.exe` 等）进行哈希/名称快速比对。
   - **绝对本地闭环**：比对过程纯在本地执行，**严禁上传任何进程名称、严禁记录历史进程、严禁发送至 API**，全力捍卫用户电脑活动隐私。
