## Physical Mouse

- [ ] Single click triggers one click response and does not start a drag.
- [ ] Double click triggers one double-click response and does not emit a delayed single click.
- [ ] Long press remains stable and release does not become a click.
- [ ] Slow drag follows the pointer without visible jumps.
- [ ] Fast throw does not lose mouse release and returns to a stable position.
- [ ] Dragging pauses idle actions and non-essential bubbles.
- [ ] Right-click opens the context menu without moving the pet.
- [ ] Dragging while the input editor is open preserves draft text.
- [ ] Dragging while Settings Center is open remains controllable and quiet.
- [ ] Dragging during focus mode does not trigger edge peek or passive feedback.

## Snap And Edge Peek

- [ ] Left edge snap and optional edge peek work.
- [ ] Right edge snap and optional edge peek work.
- [ ] Top and bottom boundaries keep the pet visible.
- [ ] Pulling the pet back from an edge clears the dock state.
- [ ] Disabling edge peek immediately returns a half-hidden pet on screen.
- [ ] Opening input immediately returns a half-hidden pet on screen.
- [ ] Opening Settings Center immediately returns a half-hidden pet on screen.
- [ ] Entering focus mode immediately returns a half-hidden pet on screen.
- [ ] Active speech is not interrupted by edge-peek animation.
