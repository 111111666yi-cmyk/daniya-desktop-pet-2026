## 4. 业务链路测试与表现

- **基础动作测试 (idle / talk / clicked / drag / sleep / happy / remind)**：在 `run.bat` 本地环境中均能被准确索引，其中 `talk` 表现出连贯的 4 帧交互，所有动作并未产生明显的视觉跳位现象。
- **缺动作与 manifest 损坏 Fallback**：系统层沿用了 v0.41 的机制，依然保持高度弹性，强制损坏时平稳回退至 `normal1/2`。
- **v0.415 扩展动作兼容性**：测试用例验证表明，即便素材包不含 `soft_idle`, `close_idle`, `bubble` 等帧组，依然成功向上折叠回退至 `idle` 及 `happy`，避免了人物消失。

## 5. 打包及 Git 安全审核

- **PyInstaller / v0.44 打包兼容性**：因为采用的是非硬编码目录检索策略，默认打包脚本不包括 `assets/private` 且 exe 会自动在运行时外挂读取此目录，设计安全。
- **Git 安全检查**：
  - `.gitignore` 配置有效。
  - `git ls-files` 和 `git status` 核验表明 `assets/private/`、`data/`、`models/`、`.env` 均处于隐身状态，未进入暂存区或受版本控制污染。
