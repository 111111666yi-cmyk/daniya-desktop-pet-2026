# 系统状态感知系统 (v0.63)

系统状态感知系统允许达妮娅在本地实时、安全、非打扰地感知电脑的运行状态，并在硬件出现瓶颈时做出温馨或傲娇的吐槽气泡提示。

## 监测指标

系统基于 `psutil` 实现在后台低频获取以下资源指标：
1. **CPU 占用**：当 CPU 瞬间占用持续超过 `90%` 时触发。
2. **内存占用**：当物理内存使用率超过 `90%` 时触发。
3. **电池状态**：当电量低于 `20%` 且处于放电状态（未插电源）时触发。
4. **网络连通性**：当检测到网络连接完全断开时触发。
5. **磁盘占用**：提供磁盘分区占用比率，用于可选辅助提醒。

## 隐私与安全铁律

- **绝对本地闭环**：所有的状态采集与分析全数在本地处理，系统不记录长期进程历史，不扫描用户进程列表与窗口标题。
- **不发送给云端 API**：采集到的软硬件数值绝对不会发送至 API，更不会自动写入 LLM 系统 Prompt，保障用户的系统活动隐私。
- **冷却控制 (Cooldown)**：对所有的 Alert 类型设置了基于时间戳的防疲劳冷却时长（默认 300 秒/5分钟），拒绝频繁弹泡骚扰用户。
- **不打断前置交互**：提醒仅使用轻量 Qt 气泡呈现，不打断主动聊天、动作播放或用户的鼠标拖拽。
