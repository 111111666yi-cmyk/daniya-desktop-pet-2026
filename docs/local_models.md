# 本地模型使用指南

达妮娅从 v0.46 开始支持连接您本地的大语言模型服务。这意味着您可以不消耗任何 API Key，在断网环境下完全私有化地运行这只桌宠！

## 支持的服务

我们内置了对于当下最流行的几种本地服务后端的解析与支持：
1. **Ollama** (`http://localhost:11434`)：全自动探测 `/api/tags`，是最推荐的本地端方案。
2. **LM Studio** (`http://localhost:1234/v1`)：请确保您在软件内开启了 "Local Inference Server" 并允许 CORS。探测 `/v1/models`。
3. **llama.cpp server** (`http://127.0.0.1:8000/v1`)：原生的 C++ 轻量级方案，支持旧电脑运行。

## 连接步骤

1. 在托盘菜单或按键盘快捷键打开 **设置中心**。
2. 导航至 **本地模型** 选项卡。
3. 选择您本地正在运行的服务类型，填入正确的 **Base URL**。
4. 点击 **[拉取模型列表]**。如果连接成功，下方的模型列表会自动刷新，选中您需要使用的模型。
5. 去到 **API / 模型** 选项卡，将 Provider 设置为 `local_openai_compatible`（由于大部分本地服务现在都支持了 OpenAI 接口规范，底层调用统一采用兼容协议），将刚刚确定的 Base URL 和 Model 填入保存即可。

## 下线自动回退 (Fallback)

如果在您关机或重启后，您忘记了打开 Ollama/LM Studio 导致服务掉线，**达妮娅不会崩溃**。
她的内部错误处理机制会自动捕获到本地端口拒绝连接 (`Connection refused`)，并将回退到默认回复。一旦您重启本地服务，下一句话她就会立刻恢复连接。

## 许可证说明
目前达妮娅不包含内置的自动下载器（将在 v0.47 引入），且不会在安装包内携带任何侵权的闭源模型或未授权的大语言模型切片。您必须自行下载如 Gemma, Llama 3, Qwen 等模型，并自行对其输出的准确性、安全性以及遵循对应的开源许可证负责。
