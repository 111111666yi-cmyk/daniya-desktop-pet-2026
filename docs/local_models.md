# 本地模型配置与使用指南

本指南将帮助您在 Daniya Summer Desktop Pet 桌宠中配置和运行本地大语言模型（LLM）。

---

## 1. 为什么不内置模型权重？
桌宠不内置任何模型的权重文件。这是因为：
1. **体积限制**：即便最轻量的大模型也有数百 MB，主流模型多达数 GB，打包内置会导致软件体积过大、分发困难。
2. **硬件差异**：不同用户的硬件（显存/内存）差距巨大。由用户根据自身硬件在本地运行（如 Ollama）并加载适合的模型是最优方案。
3. **开源许可合规性**：Llama 3、Gemma 2 和 Qwen 2.5 等开源模型皆受各自版权方的许可证（如 Meta Llama 3 社区许可协议、Google Gemma 服务条款等）约束。内置打包可能会违反这些协议的分发条款。

因此，本软件坚持**“用户确认许可证 -> 自主下载/启动 -> 连接加载”**的合规原则，绝对不会执行任何静默下载。

---

## 2. 推荐项：Qwen2.5 0.5B 说明
项目默认推荐配置 **Qwen2.5 0.5B Instruct** 模型：
* **参数量**：0.5B (约 5 亿参数)
* **磁盘占用**：约 397MB 左右
* **配置要求**：内存 >= 4GB 即可流畅运行，CPU 即可跑出极高速度，不依赖独立显卡。
* **特性**：中文理解能力优秀，适合作为桌宠在低配或办公环境下的对话底座。

---

## 3. 大模型引擎安装与使用

### A. Ollama 引擎（强烈推荐）
1. 访问官方网站 [ollama.com](https://ollama.com) 并下载安装适用于 Windows 的版本。
2. 安装后启动 Ollama（任务栏托盘中会出现小羊驼图标）。
3. 使用快捷键 `Win + R` 打开 `cmd` 或 `powershell` 命令行，运行：
   ```bash
   ollama run qwen2.5:0.5b
   ```
4. 等待拉取完成后，您就可以在命令行与其对话。
5. 在桌宠的「本地模型」页面：
   * Base URL 输入：`http://localhost:11434`
   * 点击「拉取模型列表」即可识别到下载好的模型。

### B. LM Studio 引擎
1. 下载并安装 [LM Studio](https://lmstudio.ai)。
2. 在软件内搜索并下载相应的 GGUF 格式模型（例如 Qwen2.5-0.5B-Instruct-GGUF）。
3. 进入 LM Studio 的 **Developer/Local Server** 选项卡，点击 **Start Server** 开启本地 OpenAI 兼容服务。
4. 在桌宠「本地模型」页面：
   * Base URL 输入：`http://localhost:1234/v1`
   * 模型名输入您的模型标识。

### C. llama.cpp server 引擎
1. 编译或下载 [llama.cpp](https://github.com/ggerganov/llama.cpp) 发布的二进制包。
2. 通过命令行启动服务器：
   ```bash
   llama-server.exe -m your_model.gguf -c 2048 --port 8080
   ```
3. 在桌宠「本地模型」页面：
   * Base URL 输入：`http://localhost:8080/v1`

## 4. 自定义模型配置说明
如果您的模型服务使用了非标准或自建端点：
1. 服务类型选择 **Custom**。
2. 填写服务名称、API 风格（支持 `openai_compatible` / `ollama`）、Base URL 和模型 ID。
3. 高级配置中可勾选其能力标签（如 `text`、`vision` 等），并配置 API Key 的**环境变量名称**（例如 `MY_CUSTOM_KEY`，不保存明文密钥以防源码泄露）。

---

## 5. 下载助手使用说明
您可以通过桌宠的 **设置中心 -> 本地模型 -> 打开模型下载助手** 启动引导：
1. **阅读声明**：了解合规条款。
2. **选择模型**：提供推荐的 Qwen2.5 0.5B/1.5B, Gemma 2B, Llama 8B 模型。
3. **许可证确认**：您必须阅读并勾选所有协议条款，勾选后下载按钮才会被点亮。
4. **下载与保存**：点击下载后，如果是 Ollama 服务，系统将调用本地 API 进行异步流式拉取，并显示下载进度。下载完成后您可以勾选“立即将下载好的模型应用为对话模型”。

## 6. 常见问题 (FAQ)

### Q: 切换模型后没有生效？
* **A**：请确认您点击的是 **「设为当前模型」** 或在“文本模型切换”中执行 **「直接切换」**，而不仅是保存配置。保存只写入 Profile；切换会先调用 `ProviderManager` 验证目标模型，验证成功后才写入 `active_text_profile_id`。

### Q: Ollama 未启动？
* **A**：连接测试如果提示 `WinError 10061` 表明本地服务未启动。请确认 Windows 右下角托盘是否有 Ollama 图标，若无请双击打开 Ollama 程序。

### Q: 模型列表为空 / 下载失败？
* **A**：拉取列表需要先连通 Base URL。如果下载失败，请确认您的网络连接是否顺畅（访问 Hugging Face / Ollama 官方网络是否被墙或超时）。

### Q: 许可证未确认无法下载？
* **A**：为了安全和合规，下载助手必须全部勾选许可协议复选框，表明您已知晓并同意有关服务条款。

### Q: 本地服务超时？
* **A**：模型首次加载可能需要几秒到十几秒的初始化时间，您可以适当在配置文件中调整 `timeout` 值（默认本地模型配置的超时已延长至 60 秒）。
