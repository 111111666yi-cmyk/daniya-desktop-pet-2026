# v0.46 本地模型架构验收报告

在本阶段中，我们成功实现了达妮娅桌面宠物对本地大模型运行环境的支持。本次更新**没有自动下载或托管模型**，严守了合规和隔离红线。

## 新增文件清单
- **核心控制器**：`src/local_model_manager.py` (抽象的探测与配置管理器)
- **花名册字典**：`src/model_catalog.py` (预留对未来本地下载器的支持)
- **系统级设置**：`config/local_model_config.json` (记录最后连接的地址)
- **占位与目录保护**：`models/.gitkeep`
- **使用文档**：`docs/local_models.md`

## 修改文件清单
- **系统设置中心**：`src/settings_window.py` (新增了完整的“本地模型”图形操作面板)
- **新手安装引导**：`src/first_run_wizard.py` (增加并连通了“C. 本地大模型模式”)
- **构建环境**：`.gitignore` 与 `pack.bat` (双重过滤排除了 `models/` 目录的体积侵入)

## 遗留问题 / 注意事项
1. 用户在“本地模型”选项卡测试出可以使用的模型之后，**必须手动去“API/模型”选项卡中选择 `local_openai_compatible` 并填入相应的 Base URL 和 Model Name** 才算实际连接到达妮娅大脑。设置中心未来的改版中可以将这两个页面合并或增加“一键应用到当前 Provider”的按钮。
2. v0.47 下载器入口已被强制置为灰色的按钮，并在上方添加了黄色边框的醒目开源协议许可提示。

## 建议
**当前 v0.46 已完全符合要求，无任何遗留的致命问题**。网络隔离与本地代理打通顺畅。建议您可以开启 v0.47。
