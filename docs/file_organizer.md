# 安全文件整理助手 (v0.62)

安全文件整理助手在桌宠中提供了一套本地、安全且透明的文件归类管理工具。它秉持“预览优先、用户确认、绝对不物理覆盖、绝不删除”的终极安全原则。

## 分类规则

扫描的文件默认通过其扩展名进行以下分类：
- **images** (图片): `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`
- **documents** (文档): `.pdf`, `.docx`, `.txt`, `.md`, `.xlsx`, `.pptx`
- **archives** (归档): `.zip`, `.rar`, `.7z`
- **code** (代码): `.py`, `.js`, `.ts`, `.html`, `.css`, `.json`, `.yaml`, `.yml`
- **audio** (音频): `.mp3`, `.wav`, `.flac`
- **video** (视频): `.mp4`, `.mov`, `.mkv`
- **others** (其它): 无法匹配上述扩展名的其它文件

## 安全策略

1. **绝对不自动整理/物理删除**：助手完全依赖用户提供明确的 `source_dir` 和 `target_dir`，不默认整理桌面，不发生物理删除行为（所有操作均为 `shutil.move`）。
2. **预览先行 (Dry-Run)**：任何整理开始前，必须生成 `FileOrganizerPlan` 面向用户进行预览展示。
3. **同名文件重命名保护**：当目标目录已存在同名文件时，系统自动对新文件重命名（例如 `photo.png` -> `photo_1.png`），绝不覆盖原有数据。
4. **敏感与隐藏文件绝对跳过**：
   - 自动忽略以 `.` 开头的文件/文件夹，以及系统隐藏属性的文件夹。
   - 自动排除包含敏感关键词（`.env`、`sk-`、`api_key`、`secret`等）的文件。
   - 自动剪枝排查常见敏感工程目录（`.git`、`.venv`、`models`、`backups`、`dist`、`build`、`release`、`data`等）。
5. **恢复机制**：整理过程实时持久化至本地运行时 `move_log.json`，并支持利用日志生成一键恢复（Restore）方案，安全将文件返还原处。
