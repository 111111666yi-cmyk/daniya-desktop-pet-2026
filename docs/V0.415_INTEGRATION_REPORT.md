## Main Pet Display Regression

Root cause:

- The h-stage window did not replace the main pet. The main regression risk was startup visibility and action compatibility:
  - saved coordinates could leave the pet mostly off-screen;
  - v0.415 actions such as `soft_idle`, `close_idle`, and `bubble` needed explicit v0.41 display fallback before reaching animation playback.

Fixes applied:

- `PetWindow.show_at_config_position()` now clamps invalid/off-screen coordinates and defaults to a visible right-side position.
- Startup logs include `PetWindow created`, manifest details, selected frame path, pixmap load state, and window geometry/visibility.
- `AnimationManager` maps v0.415 extended actions to v0.41 playable states.
- `AssetManager` adds aliases for extended actions and logs manifest load status.

Current status:

- `run.bat` starts the app.
- The visible main window is `Daniya Summer Desktop Pet`.
- Current verified geometry is `1099,555,192x162`.
- Current pixmap is non-empty.
