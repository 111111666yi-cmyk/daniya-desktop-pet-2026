## v0.81 本地养成

提交：`2bcc595`

新增内容：

- 默认关闭的纯本地养成中心；
- 每日补给、硬币、背包、喂食和成长等级；
- 衣柜、服装装备和好感度/等级解锁条件；
- `characters/daniya/items.json`、`outfits.json` 及模板角色包示例；
- 设置中心和右键菜单入口；
- `tests/test_growth_manager.py` 回归覆盖。

数据与隐私：

- 用户状态写入 ignored `data/growth_state.json`；
- 不依赖文本 Provider；
- 不把养成数据发送到云端；
- 未启用时拒绝改变养成状态。

## v0.82 环境与内容感知

提交：`991ebda`

新增内容：

- 默认关闭的 Open-Meteo 天气读取；
- 用户确认坐标后才允许天气请求；
- 后台线程请求和低频降雨提醒；
- 仅检测受支持播放器进程名的媒体存在性；
- 不读取窗口标题、歌名、歌词、文件路径或播放列表；
- 来自角色包 `ambient_events.json` 的低频小剧场；
- 专注模式统一抑制主动环境提示；
- `tests/test_environment_awareness.py` 回归覆盖。

数据与隐私：

- 不使用天气 API Key；
- 天气、媒体、小剧场均默认关闭；
- 环境功能配置保留在本地；
- 媒体感知不采集正在播放的具体内容。

## v0.83 长期记忆与观察日记

提交：`7b149b3`

新增内容：

- 默认关闭的对话级长期记忆；
- 本地稀疏词向量与余弦相似度检索；
- 只向文本 Provider 注入当前问题相关的 top-k 记录；
- 设置中心可查看、调整容量并清空长期记忆；
- API Key、Token、密码和密钥样式文本拒绝入库；
- 从最近 1-30 天事件日志生成观察日记；
- 日记发送前二次确认；
- Provider 失败或仅返回本地 fallback 时不保存为成功日记；
- `tests/test_long_term_memory.py`、`test_observation_diary.py` 和 prompt 回归覆盖。

数据与隐私：

- 长期记忆和日记记录位于 ignored `data/`；
- 不进入 Git 和 Windows 发布包；
- 用户可见、可关闭、可清空；
- 日记不会后台自动生成。
