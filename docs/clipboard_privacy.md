# 隐私安全剪贴板互动系统 (v0.64)

隐私安全剪贴板互动系统允许桌宠在本地监听用户的剪贴板变化，并提供轻量级建议，同时将保护用户隐私与密钥安全放在首位。

## 隐私与安全铁律

为了防止个人敏感数据与开发密钥意外泄露给云端大模型，系统引入了多重防护网：

1. **默认关闭**：本系统默认处于关闭状态。用户必须在设置中主动开启，且首次开启时会进行显著的隐私提示。
2. **绝对地纯本地过滤**：在提醒或处理剪贴板文本前，系统在本地执行正则匹配：
   - 过滤 OpenAI API Key (`sk-` 开头)
   - 过滤 Bearer Token (`Bearer` 模式)
   - 过滤包含 `api_key`、`secret`、`password`、`passwd`、`密钥`、`密码` 等关联赋值的文本
   - 过滤 18 位身份证号、11 位手机号、16-19 位银行卡号
   - 过滤大段疑似随机 token 的长十六进制/Base64串
3. **敏感信息一律本地拦截**：一旦命中上述任何过滤项，系统**绝不读取、不弹窗显示具体内容、不存入历史、更决不向 API 发送**。界面仅会发出一条本地的抽象提示：“*检测到疑似敏感或隐私内容，已自动忽略。*”
4. **长文本限制**：对于超过 `1000` 字的剪贴板文本，系统不进行自动处理或摘要，仅气泡提示字数信息，必须由用户手动点击并再次确认后方可进行分析。
5. **用户完全可知可控**：在用户要求“分析剪贴板”时，系统会明示即将把该部分截断文本发送至当前选定的云端 API 模型，并且在对话日志中明确把 `source` 标记为 `clipboard` 以便审计。
