## v0.70 Defect Closure

The supplied malicious-bug analysis was converted into regression tests and verified fixes:

- relationship, memory, and event-log reads now share their corresponding write lock;
- JSON state writes use temporary-file replacement with a direct-write fallback;
- dialogue and physical-event engine transactions are serialized;
- worker-driven physical events use the thread-safe animation/state bridge;
- network probes use a per-socket timeout and always close the socket;
- Windows-native click APIs are guarded on non-Windows systems;
- broad everyday words such as “到底” no longer force story routing;
- newly created reminders persist `notified=false`;
- file-organizer preview and execution reject sensitive/hidden roots, reserve duplicate destinations, and re-check post-preview collisions.

## Interaction Evidence

The local packaged-executable run used Windows UI Automation plus message-level mouse events because the Codex session could not move the host's physical pointer. It covered:

- quiet first-start behavior and visible character rendering;
- input-bar enable, send, hide, restore, and persistence;
- left and right edge peek plus the disabled state;
- edge-peek pause consistency while Settings Center, speech, input, or focus mode blocks passive movement;
- Provider failure labeling without a false PASS or “effective” state;
- file-organizer default-off state, preview-first behavior, and sensitive-path skips;
- system-status cooldown defaults, clipboard privacy defaults, and focus-mode suppression.

The host had one 2880x1800 display at 200% DPI. Virtual regression tests covered a negative-origin desktop and DPR values 1.0, 1.25, 1.5, and 2.0.

SmartScreen test: the unsigned EXE was copied to an isolated directory and marked with `ZoneId=3`. Windows started `smartscreen.exe` and cancelled the launch, so downloaded builds may require user confirmation.

Antivirus test: the Explorer scan action for Lenovo Anti-Virus powered by Huorong was invoked on the candidate zip. The archive remained present with an unchanged hash and no quarantine/deletion was observed; the custom result window was not machine-readable, so this is not recorded as a definitive antivirus PASS.

Local evidence artifacts and screenshots remain under ignored `scratch/` and are not included in Git or the release archive.
